What you get

Each scan lists rule ids, impact, WCAG tags, a short help link, up to three selectors, and an HTML snippet cut at 200 characters. Automated checks find roughly 57% of WCAG issues. A report is a template, not a lawyer, and it is not a compliance guarantee.

The MCP endpoint is https://a11y.aiagentpay.cloud/mcp (Streamable HTTP). The same calls are under /api/v1.

How to pay

  1. Call the tool or POST the matching /api/v1 route. Page and link checks set authorized to true. Contrast checks do not.
  2. If the URL is allowed, the response is 402 with a PAYMENT-REQUIRED header: network, amount, and the PAY_TO address.
  3. The caller signs an x402 USDC payment on Base Sepolia for tests, or Base for production, and retries with PAYMENT-SIGNATURE.
  4. The scan runs. The facilitator settles only after it succeeds. The response includes PAYMENT-RESPONSE.

A blocked URL, a robots.txt disallow, a rate limit, or a daily cap comes back as an error and is not a 402. Nothing is charged.

curl -s -D - -X POST "$ORIGIN/api/v1/scan/page" \
  -H 'content-type: application/json' \
  -d '{"url":"https://example.com/","authorized":true}'

Limits

  • 30 seconds per page, at most 10 pages per call, at most 5 redirects.
  • 10 paid calls per minute per payer address or client IP.
  • 50 pages per target domain per day, plus a global daily cap (20 by default) so Browser Run stays inside the free tier.
  • Only public http and https on ports 80 and 443. No IP literals, no private networks, no logins, no cookies, no form posts.
  • Page content is not stored. Logs keep the time, tool, price, transaction hash, payer address, and a hash of the domain.
